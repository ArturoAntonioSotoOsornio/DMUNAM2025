# Análisis No Supervisado de Datos de ECOBICI con K-Means

Este proyecto aplica **técnicas de aprendizaje no supervisado** al sistema de bicicletas públicas **ECOBICI** de la Ciudad de México, con el objetivo de identificar patrones ocultos en el uso de bicicletas.

## 📊 Descripción

Se utilizó el algoritmo de **K-Means Clustering** para agrupar registros según características como ubicación de estaciones, horario de uso, duración de los viajes, y otros datos relevantes disponibles en los archivos de ECOBICI. 

## 🧪 Tecnologías y herramientas

- Python
- Pandas y NumPy
- Scikit-learn (para K-Means)
- Matplotlib y Seaborn (visualización)

## 🧠 Metodología

1. Carga y limpieza de múltiples archivos CSV de datos de ECOBICI.
2. Normalización de datos temporales y geográficos.
3. Aplicación del algoritmo K-Means.
4. Visualización e interpretación de los clústeres.
